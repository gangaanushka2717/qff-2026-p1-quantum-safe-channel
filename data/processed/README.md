# Processed Data

This directory is reserved for cleaned or transformed datasets used in the project.

The current experiments do not produce a separate processed dataset. Processor configurations are stored in `processors/processor_A.json` and `processors/processor_B.json`.

Transpilation and noisy simulation outputs are generated by the experiment scripts and saved in `results/tables/`, including:

- `connectivity_test.json`
- `noisy_simulation.json`
- `hybrid_benchmark.json`

These files are experiment results, not cleaned input datasets, and are kept in the results directory rather than duplicated here.
